# Retail Customer Analytics — PBIP source

This folder contains the Power BI Project source for the Retail Customer Analytics capstone.

## Open locally
1. Download this repository.
2. Open `RetailCustomerAnalytics.pbip` in a recent version of Power BI Desktop.
3. If Power BI prompts for project-format support, enable the PBIP/PBIR preview option.
4. Save the opened report as `Retail_Customer_Analytics_Capstone.pbix`.
5. Publish the PBIX to Power BI Service.

A complete downloadable PBIP package was also generated in the ChatGPT conversation. The project is designed around:
- Executive Overview
- Customer & Retention
- Product & Profitability
- Revenue, profit, AOV, repeat customer rate, regional and product KPIs
- SQL + Python + Power BI portfolio workflow
